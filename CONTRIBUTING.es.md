# Contribuir

[EN](CONTRIBUTING.md) | [FR](CONTRIBUTING.fr.md) | [ES](CONTRIBUTING.es.md)

Gracias por ayudar a mejorar BouCamPhoneServ.

## Licencia y DCO

Este proyecto tiene licencia `AGPL-3.0-only`.
Cada contribución debe incluir una línea `Signed-off-by:` en el mensaje de commit para cumplir con DCO 1.1.

## Reglas simples

- mantener el proyecto fácil de arrancar
- evitar dependencias innecesarias
- preferir soluciones que sigan siendo compatibles con iPhone y Android
- documentar siempre los cambios que afecten al uso

## Antes de proponer un cambio

1. ejecuta el proyecto en local
2. revisa el panel
3. prueba al menos una página del teléfono
4. asegúrate de que la fuente OBS siga separada

## Estilo de contribución

- código legible
- archivos pequeños y coherentes
- mensajes de commit claros
- documentación actualizada cuando cambie el uso

## Si añades una función

- explica la necesidad real
- muestra cómo la descubrirá el usuario
- indica si afecta al teléfono, al panel o a OBS

## Lo que evitamos

- instalar una app en el teléfono
- romper la compatibilidad con la red local
- añadir complejidad sin un beneficio concreto
