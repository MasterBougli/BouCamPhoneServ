# Installation

[EN](Installation.md) | [FR](Installation.fr.md) | [ES](Installation.es.md)

## Requirements

- Windows for the current version
- Node.js 20 or newer
- a modern browser on the phone

## Install and Launch

```bash
npm install
npm start
```

## Local Certificate

The dashboard provides a public certificate download. Install it once on the
phone so the browser can access the camera and microphone securely.

## What to Open

- Dashboard: `http://localhost:8080`
- Phone page: `https://<pc-ip-address>:8443/phone`
