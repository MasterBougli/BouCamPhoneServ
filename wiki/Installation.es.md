# Instalación

[EN](Installation.md) | [FR](Installation.fr.md) | [ES](Installation.es.md)

## Requisitos

- Windows para la versión actual
- Node.js 20 o más reciente
- un navegador moderno en el teléfono

## Instalar y arrancar

```bash
npm install
npm start
```

## Certificado local

El panel ofrece una descarga del certificado público. Instálalo una sola vez
en el teléfono para que el navegador pueda acceder a la cámara y al micrófono
de forma segura.

## Qué abrir

- Panel: `http://localhost:8080`
- Página del teléfono: `https://<direccion-ip-del-pc>:8443/phone`
